# Arquitectura

Stack:
- MongoDB Community 8.2 en Docker.
- Laravel 13 + PHP 8.3–8.5.
- `mongodb/laravel-mongodb:^5.11`.
- API REST JSON.
- Vue 3 + Vite + Axios.

Backend:
Route -> Controller -> FormRequest -> Service -> Repository -> Model -> MongoDB.

Frontend:
View -> Components -> Service Axios -> API.
