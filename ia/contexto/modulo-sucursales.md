# Módulo Sucursales

Colección: `sucursales`.

Campos:
- nombre
- direccion
- telefono
- correo
- ciudad
- departamento
- fecha_apertura
- tipo_sucursal
- estado

Operaciones REST:
- GET /api/sucursales
- POST /api/sucursales
- GET /api/sucursales/{id}
- PUT /api/sucursales/{id}
- DELETE /api/sucursales/{id}

MongoDB utiliza `_id` generado automáticamente.
